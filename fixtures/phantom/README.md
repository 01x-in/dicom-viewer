# Phantom fixtures

Synthetic DICOM generated by [tools/phantom](../../tools/phantom/phantom.py). Released under CC0 1.0. It contains no real or licensed data, and no licensed data may be added to this repository.

| Series | Transfer syntax | Files |
|---|---|---|
| `ct-evrle` | Explicit VR Little Endian | 64 axial slices |
| `ct-j2k` | JPEG 2000 lossless | the same 64 slices |
| `seg-body-bone` | binary DICOM SEG (highdicom) | 1 multiframe instance referencing every `ct-j2k` slice |
| `seg-inserts` | binary DICOM SEG | 1 instance referencing the 48 `ct-j2k` slices that have inserts |
| `seg-overlap` | binary DICOM SEG | 1 instance referencing 21 `ct-j2k` slices, with two segments that share pixels |
| `seg-mismatch` | binary DICOM SEG | 1 instance referencing 21 `ct-j2k` slices, whose own planes do not match the CT |
| `seg-fractional` | fractional DICOM SEG | 1 instance referencing 21 `ct-j2k` slices; the fractions are only ever 0 or 1 |
| `ct-tilted` | JPEG 2000 lossless | 16 slices of the same picture, stacked along a line that leans 15° from the slice normal. In a second study |
| `ct-nonuniform` | JPEG 2000 lossless | 16 slices of the same picture, 2.5 mm apart except for one 5 mm gap after the 8th. In the same second study |

Geometry: 128×128 pixels, 1.5 mm pixel spacing, 2.5 mm slice spacing, orientation `[1,0,0,0,1,0]`, patient position HFS. Both series share a study and a frame of reference.

| Region | HU | Where |
|---|---|---|
| Outside the body | −1000 | |
| Body | 40 | circle of radius 56 px |
| Left marker | 200 | rows 40–46, columns 100–106 (patient left) |
| Air insert | −1000 | centre row 36, column 64, slices 9–56 |
| Water insert | 0 | centre row 92, column 64, slices 9–56 |
| Fat insert | −100 | centre row 64, column 36, slices 9–56 |
| Bone insert | 1000 | centre row 64, column 92, slices 9–56 |

The two last series are the ones a viewer cannot reformat into other planes (MPR): a tilted gantry, and a missing slice. They are in a study of their own (`study-fallback`), with the same frame of reference, so the main study's series list does not change. The mock server reads the series directories by name, so the main study is always the first one.

Stored values are unsigned 16-bit with `RescaleIntercept −1024`. Slice numbers above are 1-based instance numbers.

The five SEGs name instances of `ct-j2k`. Their dates, UIDs, and `ContributionDateTime` are fixed so regeneration is byte-for-byte reproducible for a given highdicom version (pinned in `tools/phantom/uv.lock`).

| SEG | Segments | Covers |
|---|---|---|
| `seg-body-bone` | 1 `Body` (the 40 HU disc), 2 `Bone insert` (the 1000 HU disc, cut out of the body segment) | every slice; the bone insert on slices 9–56 only |
| `seg-inserts` | 1 `Air`, 2 `Water`, 3 `Fat`, 4 `Bone`: each is the disc of the insert with that HU | slices 9–56 |
| `seg-overlap` | 1 `Slab` (rows 56–72 inside the body), 2 `Disc` (radius 20 px at the centre of the body); they share the pixels where the disc crosses the slab | slices 21–41 |
| `seg-mismatch` | 1 `Shifted disc` (radius 16 px at the centre) | slices 21–41 |
| `seg-fractional` | 1 `Water` and 2 `Fat`: the discs of those inserts | slices 21–41 |

`seg-overlap` cannot be one labelmap, so a reader gets two layers. `seg-mismatch` names the right `ct-j2k` instances, but its own frame of reference is another one and its planes are 12 mm away from the CT's along the columns: a viewer that matches by SOP instance finds the slices, and a geometry check must still say the planes do not agree. `seg-fractional` is of the fractional type, which the viewer's own reader does not take, so it goes through the Cornerstone adapters.

To regenerate:

```bash
cd tools/phantom && uv run python phantom.py ../../fixtures/phantom
```

CI fails if the regenerated files differ from the committed checksums.
