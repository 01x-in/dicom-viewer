A DICOM viewer you install like any other package.

Add one component to React, Next.js, Vue, Nuxt, or a plain page. You get scrolling, window and level, measurements, segmentation overlays, layouts, and reformatted planes, built on Cornerstone3D, with no bundler setup.

npm install @01x/dicom-viewer-core @01x/dicom-viewer-react

One component, three setups

Give it a data source and a study UID. It fills its parent, so the parent needs a height. 

npm install @01x/dicom-viewer-core @01x/dicom-viewer-react

'use client';
import { createDicomWebDataSource, type ViewerOptions } from '@01x/dicom-viewer-core';
import { DicomViewer } from '@01x/dicom-viewer-react';

// Keep options the same between renders. A new object restarts the viewer.
const options: ViewerOptions = {
  dataSource: createDicomWebDataSource({ wadoRoot: 'https://pacs.example.org/dicom-web' }),
};

export function Viewer() {
  return (
    <div style={{ height: '100vh' }}>
      <DicomViewer options={options} studyInstanceUID="1.2.840.113619.2.55.3" />
    </div>
  );
}

What is in the box

  • Navigation

    Scroll, window and level with presets, zoom, pan, invert, cine playback, and keyboard shortcuts. The overlay shows the slice number.

  • Measurements

    Length, bidirectional, ellipse, rectangle, probe, and angle. Ellipse and rectangle report Hounsfield statistics. Export and import them as JSON.

  • Segmentations

    DICOM SEG overlays. Show, hide, recolour, and fade each segment. A binary SEG of 512×512×300 pixels with 100 segments loads in about 2 seconds.

  • Layouts and planes

    Four layouts, series dragged into any viewport, and axial, sagittal, and coronal planes with crosshairs. A series that cannot be reformatted shows slices and says why.

  • Your framework

    React 19, Next.js (Turbopack and webpack), Vue 3.5, Nuxt, or plain HTML. The same interface everywhere, with a headless core underneath if you want your own.

  • Made to be restyled

    Light and dark themes, three palettes, and every colour as a --dv-color-* CSS property. Keyboard accessible, and it passes automated axe checks.

Plain facts

Not a medical device

This is software for building viewers. It is not cleared or approved for diagnosis or any clinical decision, and it comes with no warranty. Whoever ships it in a product owns that product's regulatory and privacy duties.

You own access control

The package has no login. You decide who may open which study, and your server must check it. The viewer never stores your token or puts it in a link, and its overlay hides patient-identifying tags unless you turn them on.

Where it is tested

Chromium is the tested browser. The examples also pass in WebKit, the engine of Safari. Firefox has not been tested yet. It works with DICOMweb servers and local files.
