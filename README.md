# dicom-viewer

A DICOM viewer you install from npm into React, Next.js, Vue, or Nuxt. It is built on [Cornerstone3D](https://www.cornerstonejs.org/) and aims for OHIF-level tools: window/level presets, measurements, DICOM SEG overlays with a segment panel, MPR, and layouts. It ships with a styled default UI and a headless core.

> Status: **M0 (bootstrap)**. The packages build, but there is no viewer yet. The plan and milestones are in [docs/plan.md](docs/plan.md).
>
> Package names use the `@scope/` placeholder until the npm scope is chosen.

## Packages

| Package | What it is |
|---|---|
| `@scope/viewer-core` | Headless core: Cornerstone engine, state store, tools, measurements, segmentation, DICOMweb data source |
| `@scope/viewer-elements` | Styled UI as Lit web components (`<dv-viewer>`, toolbar, panels) |
| `@scope/viewer-react` | React adapter (Vite, Next.js App Router) |
| `@scope/viewer-vue` | Vue 3 adapter (Vite, Nuxt) |

## Development

Prerequisites: Node 22.12+ or 24, pnpm 10, and [uv](https://docs.astral.sh/uv/) for the phantom generator.

```bash
pnpm install
pnpm check      # format check, lint, typecheck, test, build
```

| Command | What it does |
|---|---|
| `pnpm test` | Vitest across all packages |
| `pnpm lint` | ESLint (typescript-eslint strict, type-checked) |
| `pnpm typecheck` | `tsc` for every package and the config files |
| `pnpm build` | tsdown builds and publint checks |
| `pnpm format` | Biome formatting |

### Test data

Tests use only the synthetic phantom in [fixtures/phantom](fixtures/phantom/README.md), generated by [tools/phantom](tools/phantom/phantom.py). Real or licensed imaging data must never be committed.

```bash
cd tools/phantom
uv run pytest -q
uv run python phantom.py ../../fixtures/phantom
```
